Ты подключаешься к проекту `video-pipeline` — конвейер генерации коротких

того, что сломается, и точечные правки, чтобы прогон поехал дальше.

## ШАГ 1. Деньги — договорись ДО запуска

Видео на MiniMax дорогое, и это основная статья. Цены в
`app/services/media_prices.json`, сверены по прайсу 2026-08-22:

| Что | Ставка |
|---|---|
| MiniMax-M3 текст | $0.30 / 1M вход, $1.20 / 1M выход |
| image-01 | $0.0035 за картинку |
| Hailuo-2.3 **1080P/6с** | **$0.49 за клип** |
| Hailuo-2.3 768P/6с | $0.28 за клип |
| Hailuo-2.3-**Fast** 1080P/6с | $0.33 за клип |

Ролик на ~15 кадров: картинки ≈ $0.05, текст — центы, **видео $4–7.4**
в зависимости от модели и разрешения.

**Для первого прогона возьми дешёвый режим** — цель проверить проходимость
конвейера, а не качество картинки:
`MINIMAX_DEFAULT_VIDEO_MODEL=MiniMax-Hailuo-2.3-Fast` и 768P.

Важно: `LLM_BUDGET_USD` (по умолчанию 10) ограничивает **только текст**.
Медиа он не покрывает — предохранителя на видео нет вообще. Следи сам.

Стоимость по ходу прогона:
```
GET /api/projects/{id}/llm-costs     # ключ "media" — картинки/видео/озвучка
```

## ШАГ 3. Что почти наверняка сломается

Это не гадание — это места, про которые известно, что они не проверены.

**Промты — мои, не владельца.** `prompts/01_plan`, `02_script`,
`03_razbivka`, `04_hero`, `05_image_prompts`, `07_animation` и все 20
`check_operator/*` написаны в прошлой сессии по контрактам из кода. Они
соответствуют формату (тесты это проверяют), но **ни один не видел живой
модели**. Ожидай, что придётся крутить `05_image_prompts` и `07_animation`.
Это нормальная итерация, ради неё прогон и делается.

Настоящая библиотека владельца (40–130 КБ на промт, отточенная на реальных
роликах) лежит на его машине и в git не хранится — см. `HANDOVER.md` §2.5.

**MiniMax — четыре грабли, все проверены живыми вызовами** (текстовый
контур MiniMax выведен 2026-08-26 — п.1–3 остались как история и как
предостережение про любой релей без enforce'а схемы; медиа-контур жив):

1. **Structured outputs нет вообще.** `json_schema` и `json_object`
   принимаются с HTTP 200 и **игнорируются**. Формат держат только
   инструкция в промте + контракты `app/contracts/` + repair-retry.
   Не добавляй minimax в `GPT_STRUCTURED_RELAYS` — там список релеев,
   которые схему реально enforce'ят.
2. **`<think>` лезет в `content`.** Лечилось `reasoning_split: true`
   (ставился автоматически; вместе с текстовым контуром выпилен). Если
   увидел `<think>` в артефактах от другого reasoning-релея — это баг.
3. **`max_completion_tokens` покрывает и рассуждения.** При маленьком
   лимите `content` приходит пустой, а бюджет съедает reasoning. Пустой
   ответ модели — сначала подними лимит, потом ищи баг.
4. **Ошибки приезжают в теле при HTTP 200** — `base_resp.status_code`:
   1004 ключ, 1008 баланс, 1026/1027 модерация, 1002/1039 лимиты.
   Разбираются в `app/bots/minimax.py`, но если увидишь «успех» на пустом
   файле — смотри туда.

**Проверки нод.** `vision_check_max_rounds=2`. При исчерпании проект встаёт
в `paused` с `pause_reason.code=vision_rounds_exhausted`. Разруливается
явно, а не перезапуском:
```
POST /api/projects/{id}/vision-decision   {"action":"more_rounds"|"accept_pending"}
```

**Брейкер провайдера.** 5 инфраструктурных отказов подряд (5xx/сеть/таймаут)
→ цепь открыта на 60 с, вызовы падают сразу. 429 цепь не рвёт. Мешает —
`PROVIDER_BREAKER_ENABLED=false`, но сначала разберись, почему провайдер
отдаёт 5xx.

**Озвучка.** Идёт по HTTP API (`app/bots/elevenlabs_api.py`), браузер не
нужен. Путь проверен живьём: 44100 Гц, моно, 128 kbps. Квота ключа на
момент передачи — 10000 символов, тариф payg; закадр одного ролика ≈ 1000
символов. Если вдруг откатится на Chrome CDP — значит потерялся ключ,
проверь `ELEVENLABS_API_KEY`, не лечи это включением CDP.

По ходу прогона веди журнал в формате `docs/QA-RUN-*.md` (образец —

диапазоне, звук совпадает с картинкой. Если встал раньше — **это тоже
результат**, зафиксируй точное место и причину.

## Чего НЕ делать

- **Не пушить.** Удалённого репозитория в этом клоне нет (`git remote -v`
  пуст), инструкция из `AGENTS.md` про `git push origin <ветка>` здесь
  неисполнима.
- **Не коммитить `prompts/` и `.env`.** Первое под `.gitignore` осознанно
  (решение владельца), второе — секреты.
- **Не сужать базу храповика** `.claude/baselines/pytest-failures.txt`
  из-за того, что у тебя локально есть промты. База описывает свежий клон;
  сузишь — заблокируешь push всем остальным. Предупреждение записано в
  шапке файла.
- **Не начинать рефакторинг.** В `docs/TECH_DEBT_PLAN.md` осталось много
  открытых пунктов (журнальный реконсайлер, prompt caching, xlsx как второй
  SoT). Всё это — после первого ролика, не вместо него.
- **Не выключать fail-closed проверки** (`VP_ALLOW_STUB_CHECKS`) ради того,
  чтобы прогон проехал. Зелёный прогон с отключённым контролем качества
  бесполезен.
