# 🎬 Video Pipeline Web Studio

> **Веб-платформа генерации видеоконтента и модульный конвейер оркестрации ИИ.**  
> Интерактивная Студия (Next.js 15 + Tailwind CSS), надежный бэкенд (FastAPI + PostgreSQL 16), мультимодельный транспорт нейросетей и пошаговый контроль генераций (Human-In-The-Loop).

## 🌿 Механика Двух Веток и Процесс Разработки (CI/CD)

В репозитории поддерживаются два параллельных релизных контура:

1. **`main` (Первая механика)**  
   - Базовый стабильный контур платформы.
   - Контейнер `app` на порту `8765`.
2. **`second-mechanic` (Вторая механика / v2)**  
   - Инновационный контур.
   - Включает новый каталог нейросетей, генератор Outsee Create, боковую шторку стилей, систему промокодов, учёт балансов и расходов.
   - Контейнер `app-v2` на порту `8766` с изолированным хранилищем данных.

### 🛡️ Регламент работы с репозиторием:
- ❌ **Прямой push в ветки `main` и `second-mechanic` строго запрещён.**
- ✅ **Разработка только через Feature-ветки**: создаётся ветка `feat/...` или `fix/...` от нужной целевой ветки.
- 🧪 **Обязательный Pull Request и CI/CD**:
  - При открытии PR GitHub Actions прогоняет строгий гейт:
    - Проверка типов TypeScript (`tsc --noEmit`).
    - Линтинг Python (`ruff`).
    - Гейт дизайн-системы (*«Никакого hex вне токенов»*).
    - Изоляция арендаторов (RLS на реальном сервисе PostgreSQL).
- 🚀 **Автодеплой**: после успешного прохождения проверок и мерджа PR в `main` или `second-mechanic` запускается `release.yml`, который собирает подписанный Docker-образ и выкатывает его дайджестом на VPS через SSH.

## ⚙️ Как Всё Работает (Архитектура)

- **Интерактивная Студия (Next.js 15 + React 19):**
  - Канвас проектов с графом шагов генерации и индикацией статусов в реальном времени (SSE / WebSocket).
  - Раздел **Create** для свободной генерации картинок, видео, музыки и озвучки без привязки к сценарию.
  - Боковая шторка с пресетами арт-стилей, интерактивным предпросмотром и генератором промптов.
  - Финансовый дашборд: история расходов, баланс кредитов и активация купонов.
- **Оркестратор и Бэкенд (Python 3.11+ / FastAPI):**
  - Модульный State Machine движок шагов: сценарий → раскадровка → промпты → кадры → анимация → озвучка → монтаж.
  - Защита от сбоев: автоснятие залипших генераций, бэкапы перед сбросами, монотонный прогресс статусов.
- **Хранилище данных и безопасность:**
  - **PostgreSQL 16** развёрнут на хосте VPS и подключён через защищённый unix-сокет (база не торчит наружу в сеть).
  - Механизм **Row-Level Security (RLS)** гарантирует полную изоляцию данных между арендаторами.
  - Для медиафайлов: том `app-data` + бесшовный fallback на облачные хранилища.
- **Мультимодельный ИИ-Транспорт:**
  - Текст/Сценарии: GPT-5, Claude, Gemini.
  - Изображения: Outsee, Midjourney, Flux.
  - Видео: Veo 3.1, Kling, Runway, Luma.
  - Озвучка и SFX: ElevenLabs, Suno, faster-whisper.

## 🚀 Быстрый Старт

### 1. Запуск на Windows (в один клик)
Запустите файл **`STUDIO.cmd`** в корне репозитория и выберите пункт `[1] Запуск студии`.  
Скрипт автоматически проверит зависимости, окружение и откроет Студию в браузере по адресу `http://localhost:8765`.

### 2. Ручная установка и запуск

```bash
# Настройка Python
python -m venv .venv
.\.venv\Scripts\activate          # Windows
pip install -e ".[dev]"

# Сборка фронтенда
cd web
npm install
npm run build
cd ..

# Запуск бэкенда
python scripts/studio.py
