## 1. Что продаём

Пользователь заходит в чат, пишет, какой ролик хочет, агент ведёт его по
шагам конвейера с визуализацией. Каждый шаг показывает цену **до** запуска,
деньги списываются с предоплаченного баланса кредитов. Самый дорогой шаг —
генерация видео — последний.

Курс: **1 кредит = $1 себестоимости, маржа ×3**. Пополнение в рублях с
конвертацией по курсу в момент пополнения, все расчёты внутри в долларах.
Бесплатно всё до первой генерации видео на аккаунте.

Себестоимость ролика 70 с (24 кадра, с озвучкой) — **$5.625**, цена
**16.88 кредита**. **82% этого — видео.** Из этой пропорции следует вся
конструкция интерфейса: итерация идёт на картинках (в 54 раза дешевле
клипа), видео покупается один раз.

## 3. Чего нет и что проверить первым

**Живого Postgres код не видел ни разу.** Сессия, в которой он писался,
была помечена веб-походом: `/run` отрезан, podman не поднимается, без DNS
не поставить `asyncpg`. Всё проверено на SQLite и на копии боевой базы.

Первое дело новой сессии — закрыть эту дыру:

```bash
podman run -d --name vp-pg -p 5432:5432 \
  -e POSTGRES_PASSWORD=vp -e POSTGRES_USER=vp -e POSTGRES_DB=vp postgres:16
.venv/bin/pip install -e ".[postgres]"
psql postgresql://vp:vp@127.0.0.1/vp \
  -c "create role app login password 'app'" \
  -c "grant all on all tables in schema public to app"
TEST_DATABASE_URL=postgresql+asyncpg://app:app@127.0.0.1/vp \
  .venv/bin/python -m pytest tests/test_rls_postgres.py -q
```

**Роль обязательно обычная, не `vp`.** `POSTGRES_USER` образа —
суперпользователь, а RLS его не касается по определению: все тесты
изоляции прошли бы зелёными, не проверив ровно ничего. Это худший исход из
возможных, поэтому `test_role_is_not_superuser` стоит первым и падает
раньше остальных.

Если сессия помечена (сходил в веб) — эти команды из тула не выполнятся.
Пользователь запускает их сам через префикс `!`.

## 4. Ловушки — на них уже наступали

**`ENABLE ROW LEVEL SECURITY` не действует на владельца таблиц.** А
приложение подключается ровно владельцем. Политики были бы созданы, видны
в psql — и не применялись бы ни к одному запросу. Нужен `FORCE`. Обойти
RLS всё равно может суперпользователь и роль с `BYPASSRLS`; это не лечится
политикой, только тем, под кем ходит приложение.

**Снятие резерва — не проводка.** Первая версия писала `release` как
`+amount`, и инвариант показал удвоение: сумма дельт растёт, сумма холдов
падает, остаток скачет на два резерва. Холд ничего не списывал — он
запрещал потратить те же деньги дважды. Теперь запись с нулевой дельтой.

**Смета шага — сумма медийной и текстовой части, а не выбор.** У шага
«Картинки» есть и 24 PNG по прайсу, и проверка кадра зрением. Первая
версия возвращала только медиа и занижала холд на треть.

**Одного прогона в истории мало, и он запросто отладочный.** В проекте #2
раскадровка перезапускалась десяток раз — её «медиана» $1.90 против $0.42
чистого прогона. При тонкой истории показывается справка §6.1, резервируется
худшее наблюдение.

**`0.19 * 24` в float — это 4.5600000000000005.** Округление цены вверх
превращало пыль в лишний микрокредит: 13.69 кредита вместо 13.68. Вход
`price_micro` квантуется до дробности учёта (6 знаков).

**Три ревизии из четырёх были написаны на SQLite-only SQL** — `PRAGMA
table_info`, `sqlite_master`. Прогон миграций — первое, что делает новая
инсталляция: на Postgres она не поднялась бы вовсе. Переведены на
`sa.inspect`; тест `test_migrations_are_free_of_sqlite_only_sql` следит,
чтобы не вернулось.

**`pgrep -f "python3 -m app.main"` матчит собственную обёртку bash.**
Ищи по `"^/usr/bin/python3 -m app.main"`.

   формально не закрыт.

   дирижёр, а не автор конвейера.** Он вызывает существующие шаги, а не
   пишет свои.
4. **Объектное хранилище** — в биллинге уже есть `StorageService` на S3/R2
   с presigned URL; переиспользовать контракт, а не писать свой.
5. **Развязка с Excel** — 67 файлов из 324 знают про `project.xlsx`.
   Самый длинный этап, идёт фоном, запуск от него не зависит.

## 8. Мелочи, которые всплывут

* **`.env.example` не попал в коммит** — guard-хук блокирует файл по имени.
  Живых ключей в нём нет; там документация `DATABASE_URL`, `CREDIT_MARGIN`
  и предупреждение про роль. Добавить человеку: `! git add -f .env.example`.
* **Пути на диске привязаны к файлу базы.** `settings.sqlite_path.parent`
  служит каталогом для замка монтажной полосы (`montage_coexist`) и
  проверок харнесса. На Postgres перестанет быть источником правды — нужен
  отдельный `data_dir`. Пока безвредно, сломается тихо на объектном
  хранилище.
* **`ALLOW_UNISOLATED_TENANTS`** существует только для тестов механики
  кассы. В SaaS его включение — дыра, а не удобство.
* **Тариф озвучки одинаков на всех self-serve планах** ElevenLabs. Не
  оптимизируй озвучку: она 1.7% себестоимости, Flash/Turbo экономит 0.8%.
* **Риск ToS принят владельцем осознанно** (§12). По ElevenLabs вопрос
  закрылся в нашу пользу — коммерческая лицензия есть на любом платном
  плане. Остаётся MiniMax, а это 82% себестоимости.
