# Архив исторической документации и отчетов

В эту папку перемещены исторические отчеты тестовых прогонов, логи QA, промежуточные аудиты и заметки передач, относящиеся к прошедшим этапам разработки (лето 2026 г.).

Файлы сохранены для истории и контекста решений, но не являются нормативными источниками правды (Single Source of Truth) для текущей версии Web Studio.

Актуальная документация находится на уровень выше в docs/.
