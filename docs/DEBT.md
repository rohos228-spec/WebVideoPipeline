# Реестр долга

Единое место, где записано всё осознанно ослабленное. Правила —
`docs/ENGINEERING-POLICY.md` §12:

- исключение заводится только вместе со строкой здесь;
- число исключений может только уменьшаться, рост — красный
  `policy-check` (база: `.claude/baselines/debt.json`);
- долг старше 90 дней требует решения владельца: гасить или признать
  постоянным с обоснованием.

Погасил долг — убери исключение из гейта, вычеркни строку отсюда и
обнови базу: `python3 scripts/policy_check.py --update-debt`.
