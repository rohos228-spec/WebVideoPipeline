# Правка `.env.example` — применить вручную

Гейт этой машины не пускает агента к `.env*` ни на чтение, ни в индекс
(«В индекс не добавляются секреты и приватные ключи»). Правка ниже поэтому
описана, а не сделана: применить её нужно самому, например через `!` в
промпте.

---

## Удалить

```diff
-# Web auth (fleet + удалённое управление)
-WEB_AUTH_USER=
-WEB_AUTH_PASSWORD=
```

Пара удалена из `app/settings.py`: пароль лежал открытым текстом в окружении и
сравнивался оператором `!=` (утечка по времени ответа). Её заменили учётные
записи с argon2id.

```diff
-BILLING_JWT_SECRET=
-BILLING_JWT_LEEWAY_SEC=30
-BILLING_WEBHOOK_SECRET=
```

Связь с `llm-gateway` (Chattiq) снята целиком: платежей студия не принимает,
личность своя. Ручка `POST /api/billing-hook/topup` удалена.

## Добавить

```ini
# === Учётные записи студии (docs/SAAS-PIVOT.md §4.1) ===
# Секрет подписи сессионного токена. Пусто — режим владельца: личностей нет,
# изоляции нет, вход отключён (сегодняшняя установка на машине владельца).
# Задано — режим учётных записей: каждый запрос обязан нести токен.
#
# НЕ КОРОЧЕ 32 БАЙТ — иначе приложение откажется стартовать (RFC 7518 §3.2).
# Сгенерировать:
#   python3 -c 'import secrets; print(secrets.token_urlsafe(48))'
STUDIO_SESSION_SECRET=

# Срок сессии, часы. Двенадцать — рабочий день: вошёл утром, до вечера не
# переспрашивают. Отзыв держит token_epoch, срок — второй рубеж.
SESSION_TTL_HOURS=12
SESSION_LEEWAY_SEC=30

# Ставить ли cookie сессии с флагом Secure. По умолчанию нет: студия живёт на
# 127.0.0.1:8765 без TLS, и cookie с Secure там не установится вовсе — вход
# выглядел бы сломанным без единой ошибки. За обратным прокси с TLS — true.
SESSION_COOKIE_SECURE=false

# Ярлык этой студии. Единственный потребитель — уровень «бренд» в
# промт-библиотеке. Раньше по нему сверялся бренд биллинга; биллинга больше
# нет, и уникальности это поле не даёт.
STUDIO_BRAND=

# === Запись ответов моделей (evals/README.md) ===
# Пусто — не пишем. Задано — каждая пара «запрос → сырой ответ» кладётся в
# этот каталог; оттуда случаи переносятся в голденсеты:
#   LLM_RECORD_DIR=/tmp/vp-record python3 -m app.main
#   python3 scripts/goldens.py list /tmp/vp-record
# Ответы моделей — это содержимое роликов и десятки килобайт на вызов,
# поэтому по флагу, а не всегда.
LLM_RECORD_DIR=
```

## Проверить после правки

```bash
# 1. Секрет достаточной длины и старт проходит
STUDIO_SESSION_SECRET=$(python3 -c 'import secrets; print(secrets.token_urlsafe(48))')

# 2. Учётные записи требуют Postgres: RLS в SQLite не существует
DATABASE_URL=postgresql+asyncpg://app:пароль@127.0.0.1:5432/videopipeline

# 3. Завести админа
python3 -m app.seed_admin --email boss@studio.local
```

Отдельно: `WEB_HOST=0.0.0.0` без `STUDIO_SESSION_SECRET` теперь роняет старт с
объяснением. Раньше открытый порт закрывался `WEB_AUTH_PASSWORD`; пары больше
нет, и молча остаться с открытым `/api/fleet` (запуск команд на машинах парка)
нельзя.
