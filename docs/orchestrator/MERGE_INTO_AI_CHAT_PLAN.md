| | «ИИ-агент» (окно) | «Оркестратор» (док) |

## Как вливаем (рекомендую)

Окно «ИИ-агент» остаётся единственным чатом, отвечает в нём оркестратор. Кнопку дока «Оркестратор» убираем.

Шаги:

1. Флаг `AI_CHAT_ENGINE=orchestrator|legacy` (по умолчанию `legacy` до приёмки). Откат одним флагом.
2. Фронт: в `orchestrator-panel.tsx` при флаге `orchestrator` отправка идёт через `useOrchestratorChat({session:"studio-p{id}-{n}"})`, карточки — общий компонент `DockApprovalCard` (вынести из `studio-orchestrator-chat.tsx`). Окно, сессии, перетаскивание, режим «авто» остаются как есть.
3. Сессии окна → id сессий оркестратора `studio-p{id}-{n}` / `studio-factory-{n}`; разрешить такой формат в `_check_session`. История берётся с сервера (`orch_messages`), localStorage — только список вкладок.
4. Режим «авто» окна → автономия оркестратора (эндпоинт autonomy), а не текстовая приписка.
5. То, что умеет только «ИИ-агент», переносим в каталог оркестратора как действия с карточками:
   - правка текста кадров (`ops` → `shot.edit_field` / `shot.edit_cell_voiceover` уже есть, проверить покрытие);
   - кнопки-варианты `choices` (брифинг) → событие `choices` в стриме оркестратора;
   - `ui_actions` (открыть ноду, HITL) → событие в стриме;
   - создание/удаление проектов, добавление/удаление нод → действия с подтверждением (удаление — как сейчас, только руками или отдельной карточкой);
   - код и git из чата — оставить в legacy-ветке под админом, в оркестратор не тащить.
   Пока действие не перенесено, просьба про него уходит в старый путь (гибрид: классификатор очереди решает, куда).
6. Тесты и метки: перевести UI-проверки (`ui_run.py`) на окно «ИИ-агент», прогнать все наборы фраз (≈500) через окно.
7. Приёмка: флаг в `orchestrator` на тестовом стенде, Александр гоняет своими фразами, потом убираем док и legacy-путь.

## Риски

- две защиты на время гибрида (токены в памяти и карточки в базе) — legacy-ветку сузить до кода/git;
- бюджет трат есть только у оркестратора — всё платное идёт только через него;
- многошаговые задачи приходят после «done» старого формата — поэтому фронт на стрим оркестратора, а не перевод событий в старый SSE.
