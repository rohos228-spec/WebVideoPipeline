# Конструктор конвейера: студия заказчика

История в четырёх актах. Пивот (`01e9e5e`, 2026-08-24) снёс старый канвас
студии; 2026-08-29 его функции перенесли в новый лёгкий `/pipeline`.
2026-09-01 по решению заказчика («над дизайном канваса долго работали,
упрощённый режим — ваш, нодовый — наш») старый канвас восстановлен из
истории на `/pipeline` — но **только холст**, без оболочки: заказчик
увидел «обрезанную версию», где клик по ноде ничего не открывает
(инспектора нет) и название ролика не задать (мастера нет).
2026-09-03 **старая студия восстановлена целиком** — бывший `/` до пивота
один в один: шапка с инструментами, сайдбар проектов с мастером,
инспектор справа, панель оркестратора, чат, флот, стоимость, база,
outsee, GPT. Упрощённый режим остался на `/`.
2026-09-03, акт четвёртый: заказчик две недели развивал студию в своём
форке (`rohos228-spec/video-pipeline`, авторы Kir0029 / Cursor Agent /
AiCreator). По решению владельца **фронт взят из форка целиком** (их
`web/src` — база, наши дельты поверх), бэкенд — выборочно; спека
`docs/openspec/changes/merge-customer-fork/`.

## Два мира

| Адрес | Что это | Дизайн |
|---|---|---|
| `/` | **Упрощённый режим** — лента стадий, редакторы, чат | «Редакторский лист», светлый |
| `/pipeline?project=N` | **Старая студия** с открытым роликом: сайдбар, канвас, инспектор | «Canon C», тёмный |
| `/pipeline` | То же; ролик — из localStorage, иначе первый в сайдбаре | «Canon C», тёмный |
| `/pipeline?template=1` | **Шаблон для новых роликов** — канвас правит Workflow | «Canon C», тёмный |

Открыть схему ролика — с экрана ролика, ссылка «схема». Внутри студии
«шаблон для новых» — над канвасом; обратно — клик по ролику в сайдбаре.
Режим шаблона явный (`?template=1`): сайдбар иначе сам выбирает первый
проект, и «без проекта» не бывает, пока проекты есть.
Тема конструктора подключается скоупом `data-studio-scope`
(`web/src/app/studio-theme.css`); словари токенов двух дизайнов разведены.

## Что в старом канвасе как было

Ручки связей и типы связей (клик по метке / меню), V-меню ноды, НодСтудия
(настройки, промты, результаты, excel), панель результата, HITL-карточки и
ИИ-проверка, пульт «Работа с GPT», хранилище, монтажная доска, палитра с
поиском и группами (вставка, сохранение выделения группой, удаление),
мультивыделение рамкой правой кнопкой, Ctrl+C/Ctrl+V между роликами,
дублирование графа вниз (массовые дорожки), Excel-фид, Run-панель
(пауза/продолжить/стоп/доделки), миникарта, рамки групп, **автосейв с
дебаунсом** — всё из старой студии.

## Что добавилось в старый канвас (фишки нового конструктора)

- **Undo/redo** — Ctrl+Z / Ctrl+Shift+Z (Ctrl+Y), кнопки ↶ ↷ в тулбаре.
- **Автораскладка** — кнопка «разложить по слоям» в тулбаре.
- **«Убрать, соединив соседей»** — пункт V-меню: A → X → B станет A → B.
- **Ctrl+D** — дублировать выделение на месте; **Ctrl+A** — выделить всё.
- **Сохранение через слой `project_graph`** (не прямая запись
  `meta.canvas_graph`): сервер считает разницу и план сброса. Автосейв
  остался, но если правка жжёт уже сделанные шаги — канвас останавливается
  и спрашивает: сбросить устаревшее / применить без сброса / отменить.
- **«Штатная схема»** — кнопка в шапке схемы ролика (`POST /graph/reset`).
- **Предложения агента** — если чат предложил правку схемы, над канвасом
  баннер «применить / отклонить».
- **Режим шаблона** — старый канвас правит любой Workflow: выбор схемы в
  шапке, «+ новая», копия, переименовать, удалить, «вернуть штатную».
  (Раньше без выбранного проекта канвас показывал онбординг.)

## Студия заказчика: что пришло с форком (2026-09-03)

- **Меню съёмки** — нода `shot_menu` из палитры («Меню съёмки»): лента
  ячеек закадра и шотов, строки — поля БД, правка ячеек и полей шота
  (`/api/db/projects/N/shot-menu`).
- **Мета-агент** — в НодСтудии, вкладка «Промпты» → «Создать с ИИ-агентом»:
  компилирует мастер-промт ноды из намерения и правил, «сохранить и
  активировать» (`/api/meta-agent/*`, шаблоны в `templates/`).
- **«Генерация»** (outsee create): «Улучшить» промт через наш текстовый
  LLM, пресеты стиля, негативный промт, до 8 референсов, батч 1×/2×/4×,
  lightbox, конвертация PNG/JPG/WEBP при скачивании, отмена и удаление
  джоб, чистка истории. Вкладка kie.ai — за флагом сборки
  `NEXT_PUBLIC_KIE_CREATE=1`, по умолчанию выключена (бэкенда kie у нас нет).
- **Чат** — живой стрим ответа (`ask-stream`), кнопка «Стоп», поиск по
  диалогам и сообщениям, действия над сообщениями.
- **Канвас** — панель items, просмотр результатов ноды, таймеры
  исполнения, бейдж «−» у пустых завершённых шагов, LLM sync по нодам,
  шаг сетки 380px; ▶ в двух режимах (полный / доделать).
- **Дизайн** — Inter/JetBrains Mono, циановый акцент, стекло; живёт только
  под скоупом `data-studio-scope`, лист `/` не тронут. Гейт «hex вне
  токенов» держит наши каталоги строго, каталоги студии — исключены.

Не перенесено намеренно: kie-create (мёртвый провайдер), отпечаток ключа в
`/credits`, VPS-роутинг kie, их каталоги моделей как источник истины,
`web/out` в git. Реестр статусов и цепочка промтов форка — блоки G/H
спеки, ждут ревью.

  без правок; файлы с цветами-литералами добавлены в исключения hex-гейта
  CI, как и остальной старый канвас.
- `app/pipeline/page.tsx` — бывший `app/page.tsx` старой студии плюс:
  `?project=N`/`?template=1` в адресе, баннер предложения агента,
  «штатная схема», режим шаблона над канвасом.
- Панель оркестратора по умолчанию свёрнута в полоску внизу (было —
  раскрыта на весь холст: в свежем браузере канвас выглядел мёртвым).
- `useFleetTransfer` опрашивает `/api/fleet/transfers/active`, которого на
  сервере не было и до пивота: 404 раз в 3 с — старое поведение, не
  регрессия.
- Тонкий клиент нового фронта переехал: `lib/api.ts → lib/stage-api.ts`,
  `lib/types.ts → lib/stage-types.ts`, `ui/button.tsx` влит в `ui/bits.tsx`.
  Упрощённый режим работает на них, как раньше.
- Один токен сессии на оба мира: старый `identity-api` читает `vp.token`.
- Старый канвас грузит граф как раньше (`project.meta.canvas_graph` /
  workflow), но `workflow_id` берёт из самого графа — ролики, заведённые не
  от штатного шаблона, больше не рискуют перезаписью дефолтом.

## Чего по-прежнему нет

- **Каталог моделей с ценами по вендорам** — как в старой студии, по
  снапшотам (`node-model-catalog.ts`); мёртвые провайдеры из снапшотов не
  вычищены.
- **Касса** — `BalanceBadge` в шапке ходит в `/billing/balance`; после
  пивота (внутренний сервис) там отсутствие кассы, а не баланс.
