# Конструктор конвейера: где теперь то, что было в старом интерфейсе

Памятка для тех, кто привык к старому канвасу (до 2026-08-24). Старый
интерфейс снесён коммитом `01e9e5e`; новый живёт на `/pipeline` и с
2026-08-29 умеет всё существенное из старого — но лежит это иначе.

Главное правило нового экрана: **схема правится черновиком и применяется
кнопкой «Применить»** (с показом, что изменится и какие шаги сгорят), а
**настройки узла, не меняющие форму схемы, уезжают на сервер сразу**.

## Два режима — не путать

| Адрес | Что это | Что меняет |
|---|---|---|
| `/pipeline?project=N` | **Схема ролика** — по ней ролик идёт на самом деле | только этот ролик |
| `/pipeline` | **Шаблон** — по нему заводятся новые ролики | только будущие ролики |

Открыть схему ролика: с экрана ролика, ссылка «схема ролика».

## Карта: старое → новое

| Было в старом канвасе | Где теперь |
|---|---|
| Тянуть связь от узла к узлу | То же: от **правой точки** узла к **левой точке** другого |
| Тип связи (Связь / Ок / Не ок) | Клик по подписи стрелки — по кругу; **правый клик по стрелке** — выбрать из списка; там же «Удалить связь» |
| Крестик «отсоединить вход» | Правый клик по узлу → **Снять связи** (или кнопка в инспекторе) |
| Удалить ноду | Delete / Backspace, правый клик → **Убрать из схемы**; «**Убрать, соединив соседей**» — как раньше делал планировщик |
| Ctrl+C / Ctrl+V, буфер между проектами | То же: Ctrl+C / Ctrl+V (буфер в сессии браузера, работает между роликами); **Ctrl+D** — дублировать на месте |
| Рамка выделения правой кнопкой | **Shift + протяжка**; Ctrl+клик — добавить к выделению; Ctrl+A — всё |
| Отключить / включить ноду | Правый клик → Выключить, или кнопка в инспекторе. Выключенный узел конвейер пропускает |
| Кнопка «V» (меню ноды) | **Правый клик по узлу** — там запуск, сброс, вкл/выкл, дублирование, связи, удаление |
| ▶ Запустить шаг на ноде | Правый клик → **Запустить шаг**, или кнопка в инспекторе |
| Сброс шага | Правый клик → **Сбросить результат** (у отработавших) |
| Библиотека «+ Добавить» с поиском | Левая колонка — палитра с **поиском** по названию и коду типа |
| Вкладка «Группы» (веер агентов сцен, свои группы) | Раздел **«Группы»** внизу палитры: клик — вставить (после выделенного узла, если он один). Свои группы: выделить ≥2 узла → правый клик по фону → **«Сохранить выделение как группу»** |
| Выбор модели на ноде (каталог, вендоры) | Инспектор → раздел **«Модель»**: список моделей по роду узла (текст / картинка / видео) |
| Качество / детализация / соотношение сторон | Там же, под моделью, у узлов картинок и видео |
| Студия ноды → «Настройки» (длина ролика, лимиты кадра, голос, хвост, музыка, субтитры) | Инспектор → раздел **«Параметры шага»** у узлов Сценарий / Закадровый текст / Разбивка / Озвучка / Сборка |
| HITL-бейдж: принять / переделать / отклонить / править промт | Инспектор → раздел **«Проверка»**: ожидающие проверки с кнопками; у картинок/видео — по кадрам и «принять все» |
| Тумблер «GPT проверяет перед авто-апрувом» (искра на ребре / диалог ИИ-контроля) | Тот же раздел «Проверка», первый тумблер. Пишет `meta.auto_review_kinds`, как и раньше |
| Панель «Хранилище» на ноде | Инспектор → **«Файлы хранилища»**: обновить со стрелок, загрузить, скачать .zip, очистить, фильтр по виду |
| Пульт «Работа с GPT» (роль, проверка, формат ответа, что отдаёт, что принимает, загрузка файла, агент проверки) | Инспектор → **«Пульт оператора»** — всё то же, тот же бэкенд (`/gpt-operator/{node}`) |
| Кружок «результат готов» → панель результата | Инспектор → раздел **«Результат»**: текст, кадры, сетка картинок/видео, файлы + ссылка «открыть на листе ролика», где полный редактор |
| Промты ноды | Инспектор → раздел **«Промт»** — тот же редактор, что в ленте стадий |
| Run-панель: пауза / продолжить / стоп / автопродвижение | Шапка схемы ролика: галочка **«авто»**, кнопки **Пауза / Стоп** (пока идёт) и **Продолжить** |
| Миникарта, zoom | Есть: миникарта в углу, цвет — по состоянию узла |
| Рамки групп | Есть: узлы одной группы обведены пунктиром с подписью |
| Автосейв с дебаунсом | **Нет, намеренно**: схема применяется кнопкой через диф. Настройки узла — сразу |
| Undo | **Появился**: Ctrl+Z / Ctrl+Shift+Z и кнопки ↶ ↷ |
| Автораскладка | **Появилась**: кнопка «Разложить» / правый клик по фону |
| Копия Workflow «WF», удалить, переименовать | Шаблон (`/pipeline`): **+ новая / копия / переименовать / удалить** в шапке |

## Чего в новом интерфейсе нет

- **Монтажная доска** (таблица кадр × слоты с перегенерацией по слоту,
  свапами, тримом, загрузкой голоса/музыки) — 2600 строк старого кода, свой
  экран. Бэкенд (`/montage-board/*`) жив; в новом фронте не перенесена.
- **Excel-фид и массовая фабрика** (`excel_feed`, `mass-lanes`) — бэкенд
  жив, интерфейса нет.
- **Конфиг героя на ноде** (загрузка персонажей из Excel, ввод руками) —
  герои правятся на листе ролика в стадии «Персонажи».
- **Каталог моделей с ценами по вендорам** — сейчас плоский список; цена
  на узле показывается по коду шага.
- **Лента базы / панель флота / расходы** — отдельные экраны старого
  Studio, к конструктору не относятся.

## Клавиши

| Клавиша | Действие |
|---|---|
| Delete / Backspace | убрать выделенное |
| Ctrl+C / Ctrl+V | скопировать / вставить |
| Ctrl+D | дублировать |
| Ctrl+A | выделить всё |
| Ctrl+Z / Ctrl+Shift+Z (Ctrl+Y) | отмена / возврат |
| Shift + протяжка | рамка выделения |
| Ctrl + клик | добавить к выделению |
| Двойной клик по узлу | открыть в инспекторе |
| Правая кнопка | меню узла / связи / холста |
