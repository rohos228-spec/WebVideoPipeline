окружение, значения не печатать. Результат зафиксировать в proposal:

## Правила (те же, что на этапах 0-1)

- Ничего не переписывать целиком: врезаться в `gpt_api.chat()`,
  `run_operator_api`, `db_apply`, существующие парсеры. Минимально
  инвазивно, обратимо.
- Одна задача за раз; перед кодом — короткий план врезки, жди моего ок.
- Замеряй, не заявляй: «стало стабильнее» — только цифрой живого прогона.
- Тесты гоняются локально: `.venv/bin/python -m pytest tests/ -q`
  (venv уже стоит, Python 3.12). Известный предсуществующий фейл —
  `test_check_fix_writeback_applies_tsv`, не твой. НО: зелёные тесты ≠
  приёмка — harness-гейт в тестах выключен; приёмка этапа — серия ≥10
  живых прогонов, 0 LlmContractError после repair на приёмочном множестве,
  repair-rate ≤ порога из proposal.
