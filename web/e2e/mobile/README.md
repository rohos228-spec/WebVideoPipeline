# Изолированная мобильная приёмка

Проверяет **уже собранный static export именно этого worktree** (`web/out`).
Не запускает Next dev, backend, текущий пользовательский GUI или генерации.
Сборку и установку зависимостей выполняет lead отдельно; конфиг их не делает.

Из `web/`, после разрешения lead и успешной сборки:

```powershell
npx.cmd playwright test -c e2e/mobile/playwright.config.ts
```

При необходимости: `MOBILE_WEB_PORT` (по умолчанию 3197), `MOBILE_CHROME_PATH`
(путь к установленному Chromium/Chrome). Существующий сервер не переиспользуется:
занятый порт — ошибка, а не переключение на живой backend.

## Изоляция

- Playwright `webServer` владеет Node HTTP-сервером и останавливает его после прогона.
- Сервер слушает только `127.0.0.1`, читает только `web/out`, не проксирует запросы.
- GET API — локальные детерминированные fixtures по фактическим UI-контрактам;
  неизвестный API возвращает 404. SSE чата — одно mock-сообщение и heartbeat.
- Все HTTP-запросы браузера вне fixture-origin блокируются, WebSocket не подключается
  к серверу. Service workers отключены. Каждый тест получает новый browser context.
- Любой запрос, кроме GET/HEAD, блокируется и проваливает тест. Вход, регистрация,
  создание проектов и отправка сообщений **не выполняются**.
- Никакие другие e2e (в том числе существующие destructive studio tests) не входят
  в этот config.

## Покрытие

40 тестов: 10 сценариев × ширины 320/390/768/1440 (Chromium).
Студия и мобильные drawers; новый проект без создания; dock-чата с длинным URL,
таблицей и кодом; landing → login; login/register/forgot-password; профиль;
открытие Generation/GPT и их мобильной истории без создания или отправки.
Проверяются root/body overflow и геометрия важных панелей, полей и кнопок:
одного `overflow-hidden` на body недостаточно, чтобы тест прошёл.

Скриншоты каждого сценария, failure trace и HTML report: `artifacts/` (gitignored).
Это детерминированный layout smoke, **не** доказательство работы backend/auth/
генерации и не замена проверке на реальном iOS/Android с экранной клавиатурой.
