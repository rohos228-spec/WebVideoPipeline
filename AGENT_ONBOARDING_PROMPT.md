## Как работаем
1. **SDD через openspec.** Каждый этап оформляй как openspec-change:
   proposal.md → tasks.md → дельта-спека в `docs/openspec/changes/<id>/specs/`.
   По приёмке этапа — архивируй change и синкай дельту в спеку. Архив = часть
   приёмки, не «потом». (Образец связки — в `~/Projects/PelmenVPN/pelmenvpn-docs/openspec/`.)
2. **Ничего не переписываем целиком.** Врезаемся в существующие точки
   (`gpt_api.chat()`, `NodeRun`, `db_apply`, `vision_check_loop`). Правки —
   минимально инвазивные, обратимые, с бэкапом системных файлов.
3. **Одна задача за раз.** Перед кодом — короткий план врезки и что именно
   меняем. Не разгоняйся на весь этап сразу.
4. **Замеряй, не заявляй.** «Стало дешевле/стабильнее» — только с цифрой из
   реального прогона.
